# Code Explanation

- Identify the code or diff being explained and the user's intended behavior.
- Explain the purpose, main steps, and data flow in plain language; define necessary technical terms.
- Use a small concrete example and file/line references where useful. For changes, explain the before/after behavior and why it changed.
- Distinguish observed behavior from inferred intent and untested assumptions. Do not edit code unless requested.
