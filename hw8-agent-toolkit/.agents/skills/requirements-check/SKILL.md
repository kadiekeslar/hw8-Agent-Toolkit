# Requirements Check

- Use the supplied rubric as the source of truth; identify missing or ambiguous criteria rather than inventing them.
- Map each criterion to implementation evidence, file/line references, and tests actually run.
- Report MET, PARTIAL, or NOT MET for each criterion, explaining gaps and evidence limits. An unsupported claim cannot be MET.
- Report only; do not modify files or silently fix gaps.
